# مگابوک (MegaBook)

فروشگاه اینترنتی کتاب الکترونیکی، فارسی و راست‌به‌چپ. کاربران کتاب می‌خرند و در سایت می‌خوانند، کتابی را که هنوز در فروشگاه نیست با شابک (ISBN) درخواست می‌کنند، و کتاب‌های خودشان را برای فروش بارگذاری می‌کنند.

> **وضعیت پروژه:** در حال توسعه است و هنوز روی سرور واقعی منتشر نشده. فعلاً فقط در محیط توسعه با Docker Compose اجرا می‌شود.

---

## امکانات

**حساب کاربری**
- ثبت‌نام و ورود با ایمیل **یا** شمارهٔ موبایل (موبایل به هر شکلی، حتی با رقم فارسی)
- ویرایش نام، ایمیل و موبایل؛ تغییر ایمیل یا موبایل رمز فعلی را می‌خواهد
- تغییر رمز که بقیهٔ دستگاه‌ها را از حساب خارج می‌کند

**فروشگاه**
- فهرست کتاب‌ها با تب‌های موضوعی و صفحهٔ جزئیات هر کتاب
- نمونهٔ رایگان PDF برای کتاب‌هایی که آن را دارند
- فقط کتاب‌هایی که ادمین تأیید کرده در فروشگاه دیده می‌شوند

**سبد خرید و پرداخت**
- سبد روی سرور، برای هر کاربر (حداکثر ۵۰ کتاب)
- هشدار وقتی قیمت کتاب بعد از افزودن به سبد عوض شده باشد
- پرداخت فقط از کیف پول؛ خرید یا کامل انجام می‌شود یا اصلاً انجام نمی‌شود

**کتابخانه**
- کتاب‌های خریده‌شده و بارگذاری‌شدهٔ تأییدشده
- خواندن PDF در خود سایت؛ فایل کامل کتاب آدرس عمومی ندارد و فقط با لینک امضاشدهٔ کوتاه‌مدت باز می‌شود

**کیف پول**
- دفتر تراکنش تغییرناپذیر؛ موجودی همیشه از جمع تراکنش‌ها حساب می‌شود
- شارژ کارت‌به‌کارت با ثبت شمارهٔ پیگیری و رسید، و تأیید ادمین
- درخواست برداشت به کارت بانکی
- واریز خودکار سهم بارگذارنده با هر فروش

**درخواست کتاب**
- درخواست با شابک؛ مشخصات کتاب از Open Library گرفته می‌شود
- صفحهٔ عمومی درخواست‌های باز با «من هم می‌خواهم»، بدون نمایش هویت درخواست‌کننده‌ها
- با رسیدن کتاب به فروشگاه، درخواست خودکار «تأمین شده» می‌شود

**بارگذاری کتاب**
- فرم شش‌مرحله‌ای، پیش‌پرشده از روی شابک (جلد هم از Open Library دانلود می‌شود)
- بارگذارنده سهم خودش از هر فروش را پیشنهاد می‌دهد و ادمین قیمت را تعیین می‌کند
- داشبورد پیگیری درخواست‌ها و بارگذاری‌ها، با تعداد فروش و درآمد هر کتاب
- گفت‌وگو با پشتیبانی برای هر درخواست و هر کتاب بارگذاری‌شده

**مدیریت** (در پنل ادمین Django)
- تأیید یا رد کتاب‌ها و تعیین قیمت
- رسیدگی به درخواست‌های کتاب، با دلیل رد که برای درخواست‌کننده‌ها فرستاده می‌شود
- پاسخ به گفت‌وگوها، بستن و بازگشایی آن‌ها
- تأیید شارژها، پرداخت یا رد برداشت‌ها، و اصلاح دستی کیف پول

### در دست توسعه

- درگاه پرداخت آنلاین واقعی (فعلاً فقط درگاه آزمایشی در حالت توسعه)
- پنل مدیریت اختصاصی با ظاهر سایت
- اعلان‌ها و ارسال ایمیل یا پیامک
- نظر و امتیاز به کتاب، و نشان کردن کتاب
- فهرست واقعی پرفروش‌ها و جعبهٔ جستجو در صفحهٔ اصلی
- فراموشی رمز و تأیید ایمیل یا موبایل
- پشتیبانی برای مشکل‌های خرید و کیف پول

## فناوری‌ها

نسخه‌ها از `requirements.txt`، `package.json`، Dockerfileها و `docker-compose.yml` برداشته شده‌اند.

| بخش | فناوری |
|---|---|
| بک‌اند | Python 3.12، `Django==6.1`، `djangorestframework`، `djangorestframework-simplejwt` (JWT)، `django-cors-headers`، `pillow`، `requests`، `python-decouple`* |
| فرانت | `react ^19.2.8`، `react-router-dom ^7.18.3`، `axios ^1.20.0`، `tailwindcss ^4.3.3`، `vite ^8.2.2`، `react-icons ^5.7.0` |
| دیتابیس | PostgreSQL 16 (`psycopg2-binary`*) |
| زیرساخت | Docker Compose: سه سرویس `db`، `backend` و `frontend` |
| سرویس بیرونی | [Open Library](https://openlibrary.org) برای مشخصات و جلد کتاب از روی شابک |

\* پکیج‌هایی که نسخه ندارند، در `requirements.txt` نسخهٔ ثابت ندارند.

## اجرا روی سیستم خودتان

**پیش‌نیاز:** Git، و Docker با Docker Compose. نیازی به نصب Python یا Node روی سیستم نیست؛ همه‌چیز داخل کانتینرها اجرا می‌شود.

**۱. گرفتن کد**

</div>

```bash
git clone https://github.com/Yasamin-karima/MegaBook_OnlineBookStore.git
cd MegaBook_OnlineBookStore
```

<div dir="rtl">

**۲. ساختن فایل `.env`** در `backend/MegaBook_Backend/.env`. این مقدارها فقط برای توسعه‌اند:

</div>

```env
POSTGRES_DB=megabook
POSTGRES_USER=megabook
POSTGRES_PASSWORD=change-me
POSTGRES_HOST=db
POSTGRES_PORT=5432
DJANGO_SECRET_KEY=a-long-random-string
DJANGO_DEBUG=True
```

<div dir="rtl">

**۳. ساختن و بالا آوردن سرویس‌ها، ساختن جدول‌ها و مدیر کل**

</div>

```bash
docker compose up --build -d
docker compose exec backend python manage.py migrate
docker compose exec backend python manage.py createsuperuser
```

<div dir="rtl">

**۴. (اختیاری) دادهٔ نمونه:** ۱۱ موضوع و ۱۰ کتاب نمونه. پیش از آن باید مدیر کل ساخته شده باشد.

</div>

```bash
docker compose exec backend python manage.py seed_books
```

<div dir="rtl">

بعد از این:

| چه چیزی | آدرس |
|---|---|
| سایت | http://localhost:5173 |
| API | http://localhost:8000 |
| پنل ادمین | http://localhost:8000/admin/ |

برای خاموش کردن: `docker compose down`. برای اجرای تست‌ها: `docker compose exec backend python manage.py test`.
